# Пробная страница облачной версии

Эта ветка добавляет в GitHub Pages путь
`https://irinaneyro25-prog.github.io/my-project-vovremy1/preview/`.
Пробная страница опубликована отдельно от основного адреса и остаётся
доступной после выпуска облачной версии.

Страница `/preview/` содержит пробный код из ветки `codex/supabase-cloud`.
Облако включается вручную через Publishable key в настройках.
Локальные задачи не удаляются и переносятся только после отдельного
подтверждения импорта. Вход, синхронизация между компьютером и iPhone,
привязка Telegram, доставка при закрытом сайте и повторный импорт проверены
в рабочем проекте 18 ноября 2026 года.

У пробной страницы свой service worker и кэш. Код функции Telegram
ссылается на основной адрес сайта.

При выборе времени задачи форма предупреждает, если выбранное напоминание
уже просрочено. Соответствующее правило на сервере из
`supabase/migrations/20261118192000_skip_old_telegram_reminders.sql`
применено в рабочем Supabase.
