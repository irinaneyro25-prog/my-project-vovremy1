# Пробная страница облачной версии

Эта ветка добавляет в GitHub Pages путь
`https://irinaneyro25-prog.github.io/my-project-vovremy1/preview/`.
Главная страница сайта остаётся на текущей версии. Сначала нужно включить
публикацию этой ветки в `main`; до этого адрес `/preview/` не работает.

Страница `/preview/` содержит код из ветки `codex/supabase-cloud` на коммите
`28091c6`. Облако включается вручную через Publishable key в настройках.
Локальные задачи не удаляются и переносятся только после отдельного
подтверждения импорта. Вход и синхронизация через рабочий Supabase,
привязка Telegram, доставка и проверка на iPhone ещё требуют проверки.

У пробной страницы свой service worker и кэш. Код функции Telegram сейчас
ссылается на главную страницу сайта; до выпуска облачной версии в основной
адрес ссылка в сообщении ведёт на старую страницу.
