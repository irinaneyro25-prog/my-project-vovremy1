# Вовремя

Спокойный день. Всё важное — вовремя.

Доработка существующего планировщика: HTML/CSS/JavaScript, Node.js 24 и SQLite. Интерфейс и сервер используют общие правила задач, календаря и часовых поясов.

## Запуск с сервером

```sh
cd project
npm start
```

Приложение слушает порт 3000 на локальном интерфейсе. Сторонних npm-зависимостей нет, установка пакетов не требуется. Данные сохраняются в `project/.data/`, которая исключена из Git. Имя существующего файла SQLite сохранено для совместимости с прежними данными.

## Веб-версия без сервера

Публикуйте **содержимое `project/public/`** на статическом HTTPS-хостинге. Поддерживаются корень сайта и вложенный путь. При отсутствии API приложение сохраняет задачи, профиль и настройки в localStorage браузера. Календарь и список используют одни и те же записи. Серверные задачи автоматически в браузер не переносятся; между устройствами локальные данные не синхронизируются. Очистка данных сайта удаляет локальные задачи.

Для локальной проверки статической версии:

```sh
python3 -m http.server 4173 --directory project/public
```

### Первая публикация на GitHub Pages

В репозиторий включён готовый сценарий `.github/workflows/pages.yml`. Он проверяет приложение на Node.js 24 и публикует только `project/public/`, без SQLite и серверных данных.

1. Откройте репозиторий на GitHub → **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Publish Vovremya → Run workflow**, оставьте ветку **main** и нажмите зелёную **Run workflow**.
4. Дождитесь зелёной галочки у запуска. Адрес опубликованного приложения появится в **Settings → Pages** и в результате публикации.

Если первый автоматический запуск завершился ошибкой до включения Pages, выполните шаги выше и запустите его заново. Последующие изменения в ветке `main` публикуются автоматически. Всем посетителям доступно приложение по одной ссылке, но задачи каждого посетителя хранятся только в его браузере; регистрации и синхронизации пока нет.

После первого открытия и установки service worker статическая версия может открываться офлайн. Manifest и иконки позволяют установить приложение как PWA в поддерживающих браузерах. Manrope и Inter включены в файлы сайта вместе с лицензиями SIL OFL.

## Напоминания

Новая задача без ручного выбора получает напоминание за 60 минут. В настройках можно изменить дефолт для новых задач. Выбор в задаче имеет приоритет; «Без» явно отключает её напоминания. Варианты: 5, 15, 30 минут, 1 час, 2 часа, 1 день. Существующие напоминания задач сохраняются; прежний стандарт новых задач `[60,30]` заменяется на `[60]` при миграции SQLite.

Включите «Напоминания включены» в настройках или используйте кнопку на главной и разрешите уведомления браузеру. Разрешение запрашивается только по действию пользователя. Переключатель, разрешение и журнал показанных уведомлений относятся к текущему браузеру. Для опубликованного сайта нужен HTTPS.

Приложение проверяет расписание каждые 15 секунд и при возвращении во вкладку. Web Locks и общий журнал предотвращают дубли в нескольких вкладках в поддерживающих браузерах. Завершение, удаление и перенос задачи отменяют её старое расписание. Просроченные более чем на минуту напоминания и неудачные попытки уведомления попадают в «Пропущенные напоминания»; отметка просмотра сохраняется.

Точные уведомления при закрытой вкладке, закрытом PWA, сне устройства или остановке браузером фоновых таймеров **не гарантируются**. Service worker показывает уведомления, но не служит фоновым будильником. При следующем открытии приложение показывает пропущенное. Для гарантированных уведомлений при закрытом приложении нужен отдельный сервер/Telegram/push-сервис.

## Проверки

```sh
cd project
npm test
python3 tests/browser_smoke.py
```

`npm test` запускает проверки правил задач, дат, напоминаний и SQLite без сторонних зависимостей. Браузерный smoke требует Python Playwright и Chromium (путь можно задать через `CHROMIUM_EXECUTABLE`). Он запускает временные серверную и статическую копии, проверяет интерфейс, сохранение, уведомления, мобильный экран и офлайн-режим. Порты 3000 и 4173 должны быть свободны. Артефакты по умолчанию находятся в `/tmp/vovremya-browser`.
