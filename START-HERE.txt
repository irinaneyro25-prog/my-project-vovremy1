КОД ТВОЕГО ПРОЕКТА

В папке project — исходные файлы в прежней структуре: страницы, стили,
скрипты, серверная часть, картинки и загруженные оригиналы, если они есть.
Это текущая рабочая версия; она может отличаться от опубликованной.

КАК ОТКРЫТЬ И ПРОДОЛЖИТЬ РАБОТУ
1. Распакуй ZIP целиком, сохрани названия файлов и папок.
2. Открой папку project в редакторе кода. Посмотри README проекта, если он есть.
3. Для обычного проекта феечки с server.mjs нужен Node.js 24 или новее.
   В терминале из папки project выполни: node server.mjs
   Обычный адрес: http://localhost:3000 (проект может задавать другой порт).
4. Если есть package.json, зависимости устанавливаются заново:
   npm ci при наличии package-lock.json, иначе npm install.
   Если проект использует другой пакетный менеджер, следуй его README.
   Команду запуска ищи в scripts файла package.json.

Архив не подключает внешний хостинг, домен, оплату или другие сервисы.
Перед переносом проверь работу форм. Приём заявок на школьной публикации
может обеспечивать отдельный сервис; он не переносится вместе с файлами.
Клиентские заявки из .data, пароли .env, ключи, история Git и установленные
зависимости не входят в архив кода. Примеры .env.example сохраняются.
Точный список исключённых путей — в EXPORT-INFO.json.
Исходные файлы при скачивании не изменяются.
